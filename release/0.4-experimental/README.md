# Cargo Control ETS2 — 0.4 experimental

Тестовая версия для Windows x64 и точного EXE ETS2 1.61.1.9 с SHA-256 B70C2357CC56EB5834EE47FEA3C60B2F2D4591383FF2AC479CFD3CD254301B8C.

## Горячие клавиши

- F8 — биржа грузов для собственного прицепа.
- F9 — общий базовый список предложений для рынка грузоперевозок и заказов агентств.
- У каждого режима отдельные три слота по 48 игровых часов. Удержание клавиши не повторяет запуск.

## Что реализовано

F8 в режиме вождения выполняет один синхронный проход по компаниям. Неистёкшие предложения сохраняются. Для каждой компании запрашивается добавление пяти предложений: максимум 20 попыток штатного генератора, с проверкой фактического прироста списка. Если подходящих уникальных сочетаний нет, результат будет меньше пяти. Фактический результат выводится на экран и в game.log.txt. Во время прохода возможен заметный статтер.

Доступны три независимых слота генерации. Каждый результативный запуск занимает один слот на 48 игровых часов с момента этого запуска. Когда истекает первый таймер, освобождается один слот; остальные продолжают отсчёт. Если ни одного заказа не добавлено, слот не расходуется. Заказы каждого запуска сгорают через свои 48 игровых часов.

Автоматический генератор биржи грузов для собственного прицепа ограничен одной попыткой за вызов, а не гарантированным одним заказом: игра может отклонить кандидата. Таймеры компаний синхронизируются к общему сроку. Старые неистёкшие предложения сохраняются; просроченные освобождаются штатной процедурой игры. Одного-единственного статтера это не гарантирует: очистка, интерфейс и другие подсистемы игры тоже выполняют работу.

Сброс лимита реализован по флагу перезапуска таймеров SCS Telemetry и смене объекта экономики. Поведение при разных способах загрузки сохранения нужно проверить в ETS2. При выходе из процесса состояние лимита теряется.

## Установка

Закройте ETS2. Удалите предыдущий ets2_cargo_market_control.dll из bin/win_x64/plugins и скопируйте туда CargoControlETS2.dll. Не оставляйте обе версии одновременно. Уберите отдельный CargoMarketFix: совместное изменение тех же инструкций не поддерживается. INI CargoControlETS2.ini необязателен. Старые настройки Generation игнорируются. В INI можно сменить HotkeyVirtualKey (119 = F8) и FreightHotkeyVirtualKey (120 = F9). Клавиши должны различаться. Для ранее настроенной клавиши переименуйте старый INI в CargoControlETS2.ini. Тексты уведомлений не привязаны к названию клавиши.

Уведомления — отдельное прозрачное окно поверх игры, без захвата ввода. Используйте оконный режим без рамки. В эксклюзивном полном экране окно может быть невидимо. Русский и английский встроены. Язык читается из config.cfg в домашней папке ETS2 (учитывается -homedir); для других языков используется английский. Переводы встроены в DLL; папка translations не нужна. Полевая проверка определения языка и уведомлений ещё не выполнена.

## Проверка в игре

Это экспериментальный билд: проверены компиляция, экспорт SCS и исходные байты EXE, но игровые результаты ещё не проверены. Сначала используйте копию профиля/сохранения. При смене прицепа предусмотрена штатная очистка несовместимых предложений; этот переход также требует проверки. На время первого теста оставьте тот же прицеп.

1. Запишите несколько существующих предложений выбранной компании.
2. Вернитесь в кабину и нажмите F8 один раз. После статтера проверьте, сохранились ли прежние предложения и появились ли новые.
3. Ещё два отдельных нажатия должны добавлять предложения; четвёртое — показывать время до освобождения ближайшего слота.
4. Загрузите то же сохранение: в журнале должен появиться session limit reset, и F8 снова должна быть доступна.
5. Передайте game.log.txt после проверки, особенно строки append pass finished с фактическим приростом. Изменение прицепа, истечение 48 часов и сохранение/загрузка добавленных заказов требуют отдельной проверки. Для F9 дополнительно проверьте оба раздела меню, принятие заказа и загрузку сохранения с новыми предложениями.

## Сборка

Нужны MSVC Build Tools 2022 (C++ и Windows SDK), CMake 3.25+ и SCS Telemetry SDK 1.16.

```bat
cmake -S . -B build -A x64 -DSCS_SDK_ROOT="C:/path/to/scs_sdk_1_16"
cmake --build build --config Release
```

Результат Visual Studio: build/bin/Release/CargoControlETS2.dll.

Исходники: src/plugin.cpp — работа с рынком и ограничителями; src/notifications.cpp — окно уведомлений и выбор перевода. Чужой исходный код CargoMarketFix не включён. Профиль адресов основан на разборе точного EXE; при другой версии плагин отключается.


Префикс всех сообщений плагина в журнале: [QS - Cargo Control]. Название продукта в свойствах DLL: Cargo Control ETS2. Три таймера слотов и сроки заказов используют одно игровое время; пауза не продвигает кулдаун, сон/быстрое перемещение продвигают его вместе с игровым временем.


## Режим F9 — экспериментальный

F9 пытается добавить до пяти новых обычных заказов на компанию. Старые предложения не используются как место для записи новых: создаются дополнительные игровые объекты и слоты. Два раздела интерфейса могут отфильтровывать общий список по своим правилам; отображение и принятие заказов в обоих разделах ещё нужно проверить в самой ETS2.

Автоматическая генерация рынка грузоперевозок и агентств оставлена штатной, без ограничения одной попыткой. Новые слоты тоже получают штатное автоматическое обновление после истечения срока предложения. Ограничитель одной попытки относится к прежнему режиму биржи грузов для собственного прицепа.

F9 не требует собственного прицепа. Срок новых предложений — 48 игровых часов от конкретного запуска. Неуспешный проход не расходует слот лимита. В журнале используются строки Freight / Quick jobs append pass finished. Оба счётчика сбрасываются по тому же сигналу загрузки, что и прежде.

Защитный предел F9 — 512 слотов на компанию, максимум 20 попыток на одно новое предложение. При отсутствии подходящих маршрутов/грузов результат может быть меньше пяти. Дополнительные слоты расширяют служебные данные компании и восстанавливаются после загрузки. Эта часть проверена структурно и сборкой, но не игровым тестом. Сохраните отдельную копию профиля до первого F9: загрузка сохранения с дополнительными слотами при отключённой DLL пока не проверена. До проверки принятия заказа и повторной загрузки используйте только тестовую копию профиля.

Описание бинарного профиля и новых точек вмешательства находится в docs/freight-profile-1.61.1.9.md. Файлы src/freight.cpp и src/freight.h содержат реализацию нового рынка. Переводы уведомлений встроены в код, дополнительных файлов для них не требуется.


Официальный SDK: https://modding.scssoft.com/wiki/Documentation/Engine/SDK/Telemetry . Для офлайн-проверки лимитов включите CARGO_CONTROL_BUILD_CHECKS=ON при настройке CMake, затем выполните ctest --test-dir build -C Release --output-on-failure.
