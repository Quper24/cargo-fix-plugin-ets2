# ETS2 Cargo Market Control — 0.2 experimental

Тестовая версия для Windows x64 и точного EXE ETS2 1.61.1.9 с SHA-256 B70C2357CC56EB5834EE47FEA3C60B2F2D4591383FF2AC479CFD3CD254301B8C.

## Что реализовано

F8 в режиме вождения выполняет один синхронный проход по компаниям. Неистёкшие предложения сохраняются. Для каждой компании запрашивается добавление пяти предложений: максимум 20 попыток штатного генератора, с проверкой фактического прироста списка. Если подходящих уникальных сочетаний нет, результат будет меньше пяти. Фактический результат выводится на экран и в game.log.txt. Во время прохода возможен заметный статтер.

Лимит — три результативных нажатия за 20 реальных минут с первого результативного F8. Если ни одного заказа не добавлено, нажатие не расходуется. Все ручные предложения одной серии получают срок сгорания 48 игровых часов от первого F8. После 20 минут новое F8 начинает новую серию.

Автоматический генератор ограничен одной попыткой за вызов, а не гарантированным одним заказом: игра может отклонить кандидата. Таймеры компаний синхронизируются к общему сроку. Старые неистёкшие предложения сохраняются; просроченные освобождаются штатной процедурой игры. Одного-единственного статтера это не гарантирует: очистка, интерфейс и другие подсистемы игры тоже выполняют работу.

Сброс лимита реализован по флагу перезапуска таймеров SCS Telemetry и смене объекта экономики. Поведение при разных способах загрузки сохранения нужно проверить в ETS2. При выходе из процесса состояние лимита теряется.

## Установка

Закройте ETS2. Замените ets2_cargo_market_control.dll в bin/win_x64/plugins. Уберите отдельный CargoMarketFix: совместное изменение тех же инструкций не поддерживается. INI необязателен. Старые настройки Generation игнорируются; при необходимости в INI можно сменить только HotkeyVirtualKey (119 = F8).

Уведомления — отдельное прозрачное окно поверх игры, без захвата ввода. Используйте оконный режим без рамки. В эксклюзивном полном экране окно может быть невидимо. Русский и английский встроены. Язык читается из config.cfg в домашней папке ETS2 (учитывается -homedir); для других языков используется английский. Дополнительные переводы: translations/<код языка>.ini рядом с DLL, UTF-16 LE. Сохраняйте порядок и типы спецификаторов %llu и %u в Result и Cooldown; переводить можно только текст. Последовательность \n обозначает перевод строки. Полевая проверка определения языка и уведомлений ещё не выполнена.

## Проверка в игре

Это экспериментальный билд: проверены компиляция, экспорт SCS и исходные байты EXE, но игровые результаты ещё не проверены. Сначала используйте копию профиля/сохранения. При смене прицепа предусмотрена штатная очистка несовместимых предложений; этот переход также требует проверки. На время первого теста оставьте тот же прицеп.

1. Запишите несколько существующих предложений выбранной компании.
2. Вернитесь в кабину и нажмите F8 один раз. После статтера проверьте, сохранились ли прежние предложения и появились ли новые.
3. Ещё два отдельных нажатия должны добавлять предложения; четвёртое — показывать оставшееся время кулдауна.
4. Загрузите то же сохранение: в журнале должен появиться session limit reset, и F8 снова должна быть доступна.
5. Передайте game.log.txt после проверки, особенно строки append pass finished с фактическим приростом. Изменение прицепа, истечение 48 часов и сохранение/загрузка добавленных заказов требуют отдельной проверки.

## Сборка

Нужны MSVC Build Tools 2022 (C++ и Windows SDK), CMake 3.25+ и SCS Telemetry SDK 1.16.

```bat
cmake -S . -B build -A x64 -DSCS_SDK_ROOT="C:/path/to/scs_sdk_1_16"
cmake --build build --config Release
```

Результат Visual Studio: build/bin/Release/ets2_cargo_market_control.dll.

Исходники: src/plugin.cpp — работа с рынком и ограничителями; src/notifications.cpp — окно уведомлений и выбор перевода. Чужой исходный код CargoMarketFix не включён. Профиль адресов основан на разборе точного EXE; при другой версии плагин отключается.
