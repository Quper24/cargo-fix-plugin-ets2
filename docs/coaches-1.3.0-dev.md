# Coaches — 1.3.0 dev

## Согласованный объём

- Ветка `dev`, версия 1.3.0 dev; стабильная 1.2.0 остаётся в `main`.
- Массовое обновление автобусных предложений и ручное создание рейса.
- Свой и предоставленный автобус.
- До 24 точек маршрута, включая отправление и конечную остановку
  (до 22 промежуточных остановок, 23 участка).

## Состояние реализации

Реализован модуль Coaches и вкладка в общей DLL. Массовое обновление вызывает
штатные функции очистки и генерации по одной станции за кадр с прогрессом.
Если игра не создаёт пригодных рейсов, прежние предложения станции возвращаются.
Ручной редактор позволяет добавить, удалить и переставить до 24 точек.
Черновик строится нативными функциями игры, проверяется и лишь затем заменяет
один слот станции отправления. Старые таймеры станции удаляются штатной
очисткой, затем предложения получают новые события обновления.

Нативные функции добавления участка и проверки маршрута выполнились в
изолированном тесте для 23 последовательных участков (24 точек) на трёх
снимках ETS2 1.62. Сервисы имён, длительности и выделения массивов в этом тесте
заменены ограниченными фикстурами; это не полноценный игровой тест.
Принятие, прохождение и сохранение 24-точечного рейса ещё предстоит проверить
в игре. Предложения общие для рынка станции; выбор собственного или
предоставленного автобуса выполняется в игре.

Ручной маршрут пока состоит из обычных автобусных станций без повторов;
туристические точки не включены. Требуются данные проезжаемого пути между
каждой парой соседних станций; сохраняются штатные правила игры для смены
стороны движения (при политике 1 переход возможен только на конечной).

В прочитанной сессии ETS2 1.62.3.3 обнаружены 322 остановки и 2399
предложений. Максимум — 9 целевых точек после отправления. Настройка
штатного генератора `stops_per_route_max` равна 10. Для всех прочитанных
предложений длины массивов целей, расстояний и трёх видов времени совпали.
Массивы динамические; это основание исследовать более длинные рейсы,
но не подтверждение их полной поддержки игрой.

Диагностика: `tools/inspect_coach_session.py`, отчёт
`diagnostics/coaches/session.json`. Скрипт открывает процесс только для
чтения; игровые данные и сохранения не изменяет.

Перед выпуском необходима проверка создания и принятия рейса из 24 точек,
последовательности остановок, посадки/высадки, расписания, завершения,
сохранения и загрузки в обоих режимах владения автобусом.

## Порядок игрового теста

1. Загрузить профиль с Coaches, открыть Ctrl+Alt+F9, вкладку Coaches.
2. Считать сессию: окно временно закрывается, появляется индикатор, затем
   редактор открывается снова. В списке должны быть названия станций из игры.
3. Обновить все рейсы: прогресс идёт по станциям; после завершения заново
   открыть автобусный рынок. Проверить замену предложений на нескольких станциях.
4. Создать короткий маршрут из двух точек; найти его на станции отправления.
   Проверить принятие и завершение на предоставленном автобусе.
5. Создать маршрут с промежуточными остановками на своём автобусе. Проверить
   порядок остановок, посадку/высадку, расписание и завершение.
6. Создать маршрут из 24 точек, убедиться, что игра показывает весь маршрут;
   проверить сохранение/загрузку после принятия и переход между этапами.
7. Сменить профиль или перезагрузить сессию: старый каталог должен сброситься,
   считывание заново должно разрешить создание нового маршрута.

Логи операций имеют префикс Coaches в `game.log.txt`: число станций,
запрошенных/собранных участков, номер заменённого слота, итог обновления.
