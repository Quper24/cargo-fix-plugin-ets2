🚛 Cargo Control ETS2 обновлён до 0.7.0!

Главное изменение — поддержка дополнительных версий игры. Теперь одна DLL содержит профили для:

• 1.61.1.9 — обычная версия, поддержка сохранена;
• 1.61.1.1s — ветка temporary_1_61;
• 1.61.1.1009s — ветка Oculus;
• 1.62.0.10s — ветка public_beta.

Плагин сам выбирает профиль установленной сборки. Дополнительно проверяет нужные участки кода перед включением функций рынка. Если EXE неизвестен или проверка не прошла, изменения рынка отключаются, а причина записывается в game.log.txt.

Основная задача прежняя: уменьшить подтормаживания, связанные с генерацией грузов для собственного прицепа. Автоматический фикс работает без нажатия кнопок. Ручное добавление грузов и обновление заказов доступны через меню Ctrl+Alt+F9.

Для обновления закройте игру и замените CargoControlETS2.dll в bin/win_x64/plugins. Существующий INI можно оставить.

⚠️ Выпуск experimental: сборка и 11 офлайн-проверок прошли, игровая проверка на каждой ветке ещё требуется. Начните с копии профиля. Поддержка Oculus относится к функциям рынка — меню внутри VR-шлема пока не реализовано. Совместимость с будущими обновлениями игры автоматически не включается.

Если столкнётесь с проблемой, приложите game.log.txt, укажите версию игры и ветку Steam.
