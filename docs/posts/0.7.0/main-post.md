🚛 Cargo Control ETS2 — автоматический фикс генерации грузов и управление рынком

Версия плагина: 0.7.0 experimental
Платформа: Windows x64, DirectX 11

Плагин предназначен для уменьшения подтормаживаний, связанных с генерацией предложений на бирже грузов для собственного прицепа. Он ограничивает число попыток генерации и сохраняет неистёкшие предложения в рамках текущего прицепа. При смене прицепа сохраняется штатная очистка неподходящих предложений.

Основной фикс включается автоматически после загрузки плагина. Открывать меню или запускать ручную генерацию для его работы не нужно. Влияние на плавность зависит от причины подтормаживаний: плагин работает с конкретным механизмом генерации рынка.

Дополнительные возможности

• Добавление грузов для своего прицепа: до пяти новых предложений на компанию с сохранением неистёкших. Игра может отклонять неподходящие варианты, поэтому предложений бывает меньше. Доступны три независимых запуска; каждый использованный слот освобождается через 48 игровых часов.

• Обновление рынка грузоперевозок и заказов агентств: старые предложения заменяются новыми штатным способом. Их количество определяется компанией и картой. После завершения обновления действует ожидание 5 реальных секунд, без квоты запусков.

• Новым предложениям ручной генерации назначается срок 48 игровых часов.

• Меню, уведомления и настройка сочетаний клавиш встроены в кадр игры. Есть русский и английский языки. Сочетания для действий по умолчанию отключены.

Управление

Ctrl+Alt+F9 — открыть или закрыть меню.
Escape — закрыть меню.

В меню можно добавить грузы, обновить заказы и назначить собственные сочетания. Перед использованием остановите грузовик. Действие выполняется после закрытия меню и возврата к вождению; полный проход по компаниям может временно задержать кадр. Само меню игру на паузу не ставит.

Лимиты добавления грузов отсчитываются по игровому времени: сон и быстрое перемещение продвигают их, пауза — нет. Перезапуск игры и обработанный сигнал загрузки сохранения сбрасывают лимиты.

Совместимость 0.7.0

Одна DLL содержит профили для следующих точных сборок:

• 1.61.1.9 — обычная версия;
• 1.61.1.1s — temporary_1_61;
• 1.61.1.1009s — Oculus;
• 1.62.0.10s — public_beta.

Сборка определяется по хешу EXE, затем проверяются нужные участки кода. При неизвестном или изменённом EXE функции рынка отключаются с записью причины в game.log.txt. Совпадение номера версии не гарантирует совместимость; будущие обновления автоматически не разрешаются.

Ветка Oculus поддержана на уровне функций рынка. Вывод меню внутри VR-шлема и VR-ввод пока не реализованы. Интерфейс использует DirectX 11.

Установка и обновление

1. Закройте ETS2 и сделайте копию тестового профиля.
2. Поместите CargoControlETS2.dll в папку Euro Truck Simulator 2/bin/win_x64/plugins. При обновлении замените прежнюю DLL; оставьте только одну версию Cargo Control.
3. Запустите игру в режиме DirectX 11. В game.log.txt должны появиться название выбранного профиля и версия v0.7.0.

Это DLL-плагин: добавлять его в менеджер модификаций не требуется. Существующий CargoControlETS2.ini можно сохранить. Настройки сочетаний записываются рядом с DLL; папка должна быть доступна для записи.

Статус выпуска

0.7.0 — experimental. Сборка и 11 офлайн-проверок прошли, включая проверки профилей по четырём образам игры. Это не заменяет игровой тест: на копии профиля проверьте оба рынка, принятие заказа и сохранение/загрузку. Сохранения с некорректно расширенными слотами от отозванной версии 0.4 этот выпуск не восстанавливает.

Для сообщения о проблеме приложите game.log.txt и, если появился, game.crash.txt. Укажите версию игры, ветку Steam и действие, после которого возникла проблема.
