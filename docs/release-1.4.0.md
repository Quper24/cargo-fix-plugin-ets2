# Cargo Control 1.4.0

Настройки интерфейса, светлая тема, фильтры регионов и случайный выбор при создании заказов.

- Добавлены 18 языков интерфейса. Украинский расположен сразу после белорусского. Румынский перевод общий для Румынии и Молдовы. «Авто» следует поддерживаемому языку игры, ручной выбор сохраняется.
- Во вкладку «Настройки» перенесены язык интерфейса, масштаб 75–300%, выбор темы и назначения клавиш. Тёмная тема включена по умолчанию; светлая использует более светлый фон и контрастные кнопки.
- Обновлён логотип, сохранена прозрачность PNG. Надписи кнопок подстраиваются под доступную ширину.
- В форме грузового заказа добавлены фильтры страны в ETS2 и штата/провинции в ATS отдельно для отправления и назначения. Кнопки с кубиком выбирают город, базу или груз из соответствующего доступного списка с учётом фильтров.
- Поля формы выровнены. Поисковые списки закрываются по клику снаружи, повторному нажатию стрелки или Esc.
- На вкладке «Рынки» слева расположено обновление заказов, справа — грузов собственного прицепа. Обновление грузов и переключатель собственного прицепа требуют подтверждённого прицепленного прицепа; добавлены подсказки.
- В русском интерфейсе Coaches переименован в «Автобусы».
- При отсутствии строки расстояния для прямого грузового заказа выполняется попытка создания с приблизительным расстоянием и предупреждением. Используется расстояние обратного направления, затем медиана известных расстояний базы, при полном отсутствии данных — условные 1000 км. Данные паромов при подстановке отсутствуют. Перед принятием проверьте маршрут, оплату и срок доставки.

## Установка

При закрытой игре замените `CargoControl.dll` в `bin/win_x64/plugins`. Существующие `CargoControl.ini` и `CargoControl.delivery-time.txt` сохраните. В папке должна быть одна DLL Cargo Control. Одна сборка подходит для ATS и ETS2 на Windows x64 с DirectX 11. Меню по умолчанию открывается по Ctrl+Alt+F9.

## Проверка

Release x64, 42/42 автоматических проверок. Проверены строки переводов и их форматные подстановки, сохранение каждого языка, наличие используемых символов в системном шрифте и DX11-рендер интерфейса. Новые переводы ещё требуют вычитки носителями; часть длинных служебных сообщений сокращена. Доступность регионов на модовых картах и подключение прицепа следует проверить в соответствующей игровой сессии.

Сохранено исправление жизненного цикла автобусных предложений из 1.3.5. Для диагностики приложите `game.log.txt`, а при вылете — `game.crash.txt`, и укажите действие, игру и её версию.
