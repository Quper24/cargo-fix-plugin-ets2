# Совместимость исполняемых файлов

Версия 0.5.0 сохраняет проверку SHA-256 известного EXE 1.61.1.9. Oculus и 1.62 не включены в поддерживаемые сборки.

Генерация вызывается через внутренние функции игры. Используются адреса кода, глобальной экономики и смещения полей объектов. Совпадение видимого номера версии или поведения генератора не подтверждает совпадение этих данных.

Для расширения поддержки нужны локальные eurotrucks2.exe конкретных сборок Oculus и 1.62 с указанием ветки и полного номера версии. Анализировать их можно без запуска и без установки соответствующей игры на компьютер разработчика. Проверка в игре с профилем, картами и сохранением остаётся необходимой.

Возможные варианты:
- Один DLL с несколькими проверенными профилями адресов для разных сборок.
- Поиск функций по сигнатурам, проверка уникальности результатов, цепочек вызовов и структуры данных. Неизвестная или неоднозначная сборка отключает изменения рынка и записывает причину в журнал.

Поиск по сигнатурам может уменьшить зависимость от небольших обновлений, но сам по себе не подтверждает совместимость ABI и структуры объектов. Проверять только 1.61/1.62 недостаточно.

Меню внутри VR требует отдельного VR-рендерера и ввода. Текущее меню Windows остаётся доступным на мониторе. VR-модуль следует активировать только при обнаружении поддерживаемого активного VR-сеанса, сохраняя обычный путь для игры без VR. Конкретный вариант интеграции определяется после проверки API соответствующей ветки.
