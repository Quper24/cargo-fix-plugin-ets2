# Cargo Control 1.0.1

Плагин для **Euro Truck Simulator 2** и **American Truck Simulator** версий **1.61 и 1.62** на Windows x64 с DirectX 11. Cargo Control ограничивает автоматический подбор грузов для собственного прицепа, чтобы снизить связанные с ним подтормаживания.

## Установка

1. Закройте игру.
2. Удалите предыдущую DLL Cargo Control из `bin/win_x64/plugins`. В старых выпусках она могла называться `CargoControlETS2.dll` или `CargoControlATS.dll`.
3. Скопируйте `CargoControl.dll` в `bin/win_x64/plugins` нужной игры. Если папки `plugins` нет, создайте её.
4. Запустите игру с DirectX 11 и откройте меню сочетанием **Ctrl+Alt+F9**. Номер `v1.0.1` указан в нижнем левом углу.

## Использование

- **Обновить грузы.** Выберите собственный прицеп. Кнопка заменяет текущий набор грузов у каждой подходящей компании на набор из максимум пяти новых различных предложений. При следующем нажатии создаётся новый набор. Срок действия каждого набора составляет 48 игровых часов. В уведомлении указано, сколько компаний получили пять предложений. Каждый из трёх доступных запусков восстанавливается через 48 игровых часов после использования.
- **Автоматическое пополнение.** При штатном обновлении биржи истёкшие грузы удаляются. Если список компании пуст, плагин делает одну попытку подобрать груз. Действующие предложения сохраняются до окончания срока или ручного обновления.
- **Обновить заказы.** Заменяет предложения рынка грузоперевозок и заказов агентств в количестве, которое определяет игра. Действие доступно из загруженного гаража. Следующее обновление можно запустить через пять реальных секунд после завершения предыдущего.

Горячие клавиши действий назначаются в меню. После сохранения они записываются в `CargoControl.ini` рядом с DLL. При первом запуске плагин может прочитать прежние сочетания из `CargoControlETS2.ini`.

## Совместимость после обновлений

После обновления игры плагин проверяет совместимость функций рынка. При несовместимости плагин записывает причину в `game.log.txt`.

## Если возникла проблема

Укажите игру, её версию и действие, на котором возникла проблема. При проблеме сохраните `game.log.txt` и `game.crash.txt`, если он появился. Отсутствие сбоев не следует из успешных офлайн-проверок.
