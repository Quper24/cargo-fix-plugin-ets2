# Cargo Control 1.3.0

## Coaches в ETS2

- Массовая замена автобусных рейсов штатным генератором игры: до 10 точек с учётом игровых навыков.
- Ручной маршрут из 2–24 точек, включая отправление и конечную остановку.
- Названия и станции из загруженной сессии. Общие предложения станции для своего или предоставленного автобуса.
- Добавление, удаление и перестановка остановок; счётчик точек и поиск с очисткой после выбора.
- Нативная сборка и проверка черновика перед заменой предложения; при массовом обновлении неудачный подбор сохраняет прежние рейсы станции.
- Обновление станций между кадрами с индикатором прогресса.

## Интерфейс

- Согласованы состояния обычных, наведённых и нажатых зелёных кнопок.
- Подсказки объясняют недоступные действия и управление маршрутом; пустые списки показывают причину вместо пустого меню.
- Пустой маршрут Coaches объясняет порядок добавления точек, кнопки остановок получили более удобный размер.
- Выравнивание полей Road Trip, сортировка городов и баз по отображаемым названиям.
- Окно центрируется при изменении разрешения, чтобы элементы оставались на экране.

## Проверки

Release x64, CTest 39/39. Проверены три снимка ETS2 1.62, отказ при изменении нативного кода, изолированная сборка 23 участков (24 точек) нативными функциями. DX11-проверка охватывает вкладки рынков, грузового заказа, Road Trip и Coaches, индикаторы и уведомления, пустой и заполненный маршрут, разрешения 1024×768 и 800×600.

Версия ресурсов 1.3.0, OriginalFilename `CargoControl.dll`. SHA-256 DLL: `5ebee7168c4b8c989b692e19b468f226e7cdbbe0dc0fe81716cffa26a3050fb9`.

Изолированный тест использует фикстуры сервисов имён, длительности и массивов; он не заменяет прохождение полного 24-точечного рейса и проверку сохранения в игре. Эти проверки не выдаются за автоматически выполненные.

## Установка

Одна `CargoControl.dll` для ATS и ETS2. Удалите предыдущую DLL Cargo Control из папки plugins, включая dev-версию, сохранив её резервную копию вне этой папки. Подробности — в [руководстве 1.3.0](README-public-1.3.0.md).
