# Любые грузы и базы — 1.2.0 dev

Во вкладке «Создать заказ», в режиме «Грузоперевозки», добавлена галочка «Показывать все грузы». По умолчанию она выключена.

При включении показываются все грузы из считанного каталога текущей игры и её модов. Ассортимент базы отправления и принимающей компании не ограничивает создание: например, можно выбрать трактор из супермаркета и любую грузовую базу в городе назначения. Подсказка при наведении поясняет оба направления, а под формой есть краткое напоминание.

Флаг передаётся вместе с конкретным запросом. Проверки интерфейса и backend допускают только известные из сессии грузы и реальные базы. Нативному генератору на время этого единственного вызова передаются выбранный груз и сохранённая игрой строка маршрута к нужному получателю. Постоянные определения ассортимента компаний не изменяются. Игра продолжает подбирать подходящий прицеп и обрабатывать предложение штатно. При отсутствии необходимых данных маршрута или физического места выдаётся ошибка, прежнее предложение не заменяется.

Без галочки сохраняются обычные ограничения ассортимента. При смене базы с включённой галочкой выбранный груз сохраняется; при выключении неподходящий обычному ассортименту выбор очищается. Road Trip этой настройкой не затрагивается.

Для собственного прицепа список уже общий для всех баз и ограничивается физической совместимостью прицепа. Этот фильтр сохранён: включение всех грузов грузоперевозок не разрешает несовместимые грузы для собственного прицепа.

Галочка «Разрешить замену одного предложения на базе отправления» удалена из грузовой формы. Замена разрешена по умолчанию: используется свободный/истёкший слот либо подходящий действующий слот. Вместимость физических парковок не увеличивается. Галочка времени доставки ×4 работает независимо.

Проверено: Release, CTest 35/35, DX11-предпросмотр формы. Проверки запросов покрывают груз вне исходящего ассортимента, получателя без такого входящего груза, отключённый флаг, неизвестный груз, одинаковые исходную и целевую базы и сохранение фильтра собственного прицепа.

После установки проверить в игре: выбрать необычный груз на базе без такого ассортимента, выбрать получателя без него, создать без отдельного разрешения замены, принять заказ, проверить прицеп и завершить доставку. Игровое выполнение такого заказа этой сборкой пока не подтверждено.
