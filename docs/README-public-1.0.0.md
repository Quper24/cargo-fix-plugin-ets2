# Cargo Control 1.0.0

Плагин для **Euro Truck Simulator 2** и **American Truck Simulator** версий **1.61 и 1.62** на Windows x64 с DirectX 11. Cargo Control ограничивает автоматическую генерацию грузов для своего прицепа, чтобы снизить связанные с ней подтормаживания. Неистёкшие предложения сохраняются.

## Установка

1. Закройте игру.
2. Удалите предыдущую DLL Cargo Control из `bin/win_x64/plugins`. В старых выпусках она могла называться `CargoControlETS2.dll` или `CargoControlATS.dll`.
3. Скопируйте `CargoControl.dll` в `bin/win_x64/plugins` нужной игры. Если папки `plugins` нет, создайте её.
4. Запустите игру с DirectX 11. Откройте меню сочетанием **Ctrl+Alt+F9**. Номер `v1.0.0` указан в нижнем левом углу.

## Использование

- **Добавить грузы.** Выберите собственный прицеп и запустите добавление. Плагин добавляет до пяти различных предложений на компанию за запуск и сохраняет неистёкшие предложения. Количество зависит от доступных грузов и направлений. В уведомлении указано, сколько компаний получили все пять. Каждый из трёх доступных запусков восстанавливается через 48 игровых часов после использования.
- **Обновить заказы.** Заменяет предложения рынка грузоперевозок и заказов агентств. Количество предложений определяет игра. Действие доступно из загруженного гаража. Следующее обновление можно запустить через пять реальных секунд после завершения предыдущего.

Горячие клавиши действий назначаются в меню. После сохранения они записываются в `CargoControl.ini` рядом с DLL. При первом запуске плагин может прочитать прежние сочетания из `CargoControlETS2.ini`.

## Совместимость после обновлений

После обновления игры плагин проверяет совместимость функций рынка. При несовместимости плагин записывает причину в `game.log.txt`.

## Если возникла проблема

Укажите игру, её версию и действие, на котором возникла проблема. При проблеме сохраните `game.log.txt` и `game.crash.txt`, если он появился. Отсутствие сбоев не следует из успешных офлайн-проверок.
