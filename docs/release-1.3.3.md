# Cargo Control 1.3.3

Изменения относительно опубликованной версии 1.3.0.

## Исправления

- Исправлено длительное зависание при чтении загруженной сессии: каталог обрабатывается небольшими порциями между кадрами, с прогрессом по базам.
- Повторяющиеся определения компаний и грузов кэшируются. Большие карты и моды больше не расходуют лимит чтения повторной обработкой одинаковых данных каждой базы.
- Исправлена ошибка `Cargo list exceeds the scan budget`, возникавшая из-за повторного подсчёта общих списков грузов.
- Чтение прерывается при смене или выгрузке игровой сессии; незавершённый каталог не используется для создания заказов.
- После ошибки чтения показывается предложение повторить операцию вместо подсказки загрузить уже загруженный профиль.
- Улучшена совместимость обработки оконных сообщений с другими плагинами при завершении работы интерфейса.

## Поиск и горячие клавиши

- Общее поле поиска заменено независимым поиском прямо в полях городов, баз, грузов, заданий Road Trip и остановок Coaches.
- Поддерживаются выбор мышью, стрелки, Enter и отмена через Esc.
- На вкладке «Рынки» можно изменить сочетание открытия меню. Добавлены проверка конфликтов, сохранение настроек и возврат к Ctrl+Alt+F9.
- Добавлена заметная подсказка восстановления настроек через удаление `CargoControl.ini` и подробная справка.
- Подровнены пропорции, размеры кнопок и расстояния в блоке горячих клавиш.

## Проверки и установка

Release x64, 40/40 автоматических проверок. Добавлен регрессионный тест большой карты с общими списками грузов у нескольких баз; проверены поэтапность чтения, кэширование, повторный запуск и некорректные данные. DX11-проверка включает экран ошибки чтения и существующие страницы интерфейса. Пользователь подтвердил работу исправления в игре.

Одна `CargoControl.dll` для ATS и ETS2. Закройте игру перед заменой DLL, сохраните настройки и оставьте в папке plugins одну версию Cargo Control.
