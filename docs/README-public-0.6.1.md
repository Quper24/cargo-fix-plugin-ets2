# Cargo Control ETS2 0.6.1 — beta

Плагин для Euro Truck Simulator 2 1.61.1.9, Windows x64, DirectX 11.

![Меню](previews/menu-0.6.1.png)

## Управление

Ctrl+Alt+F9 открывает встроенное в кадр игры меню. Escape или кнопка закрытия закрывает его. Игра сохраняет фокус; отдельные окна меню и уведомлений не создаются.

- **Добавить грузы:** до пяти новых предложений на компанию для собственного прицепа, с сохранением неистёкших предложений. Три независимых слота по 48 игровых часов. Игра может отклонить кандидатов, поэтому грузов бывает меньше пяти.
- **Обновить заказы:** штатное обновление рынка грузоперевозок и заказов агентств. Старые предложения заменяются; количество определяется компанией и картой. После завершения обновления действует кулдаун 5 реальных секунд, без квоты запусков.
- **Сочетания:** по умолчанию отключены. Выберите поле, нажмите сочетание и сохраните. «Сброс» отключает назначение. Одинаковые сочетания и Ctrl+Alt+F9 для действий запрещены. Escape отменяет захват сочетания.

Остановите грузовик перед генерацией. Действие выполняется в потоке игры после возврата в режим вождения. Полный проход по компаниям может временно остановить кадры. Меню само по себе игру на паузу не ставит.

Настройки сохраняются в CargoControlETS2.ini рядом с DLL; необходим доступ на запись. Используются значения Bindings/Cargo и Bindings/Freight. Прежние параметры General для клавиш игнорируются. Перезапуск игры и сигнал загрузки сохранения сбрасывают лимиты; разные варианты загрузки входят в программу бета-теста.

## Уведомления

Сообщения рисуются прямо в кадре DirectX 11 с логотипом и фирменными цветами. Результат получает собственный бюджет 7 секунд. Долгая пауза генерации не расходует его целиком; время вне фокуса и при открытом меню не учитывается. После закрытия меню непрочитанный результат снова виден в игре. Русские и английские тексты встроены в DLL; для других языков используется английский.

## Установка и совместимость

1. Закройте ETS2 и сделайте копию тестового профиля.
2. Поместите CargoControlETS2.dll в bin/win_x64/plugins. Оставьте только одну версию плагина.
3. Загрузите профиль и откройте меню Ctrl+Alt+F9.

Для работы не нужны отдельные изображения, шрифты или дополнительные DLL плагина: библиотеки интерфейса скомпонованы внутрь, логотип встроен. Используются системные компоненты DirectX 11 и шрифт Segoe UI.

Профиль генерации пока поддерживает только проверенный EXE 1.61.1.9 с SHA-256:

B70C2357CC56EB5834EE47FEA3C60B2F2D4591383FF2AC479CFD3CD254301B8C

При несовпадении EXE или проверок инструкций изменения рынка отключаются. Если установка интерфейса не удалась, генератор также восстанавливается и плагин отключается с записью причины в game.log.txt.

DirectX 12, OpenGL, Vulkan и интерфейс внутри VR-шлема в этой версии не реализованы. Oculus и 1.62 ещё не включены в поддерживаемые профили. Вывод на монитор в Oculus тоже требует отдельной проверки соответствующего EXE и графического пути.

Автоматическая генерация рынка грузоперевозок и агентств остаётся штатной. Для собственного прицепа ограничивается одна попытка автоматического генератора за вызов. Это не гарантия одного готового заказа или полного отсутствия статтеров.

## Проверка и обратная связь

Прошли офлайн-тесты лимитов, сочетаний, времени уведомления и списка компаний. DirectX-тест на программном устройстве WARP проверяет настоящие пиксели интерфейса, загрузку логотипа, сохранение viewport, изменение размера буфера, восстановление оконной процедуры и установку/снятие перехвата Present. Изображения выше получены из этого теста. Эти проверки не заменяют тест в ETS2 на реальном видеодрайвере.

Проверьте в игре наведение и нажатие кнопок, отсутствие движения камеры при работе мышью в меню, назначение и сохранение сочетаний, появление результата после генерации, Alt+Tab и смену разрешения. Совместимость с другими графическими оверлеями и плагинами требует игрового тестирования; заранее она не гарантируется.

В отчёт приложите версию плагина, полный номер ETS2, видеорежим, список плагинов, шаги воспроизведения и game.log.txt. При вылете нужен последний блок game.crash.txt. Сообщения имеют префикс [QS - Cargo Control]. Перед публичной отправкой проверьте журналы на персональные данные.

## Сборка

Нужны Visual Studio 2022 Build Tools (C++, Windows SDK), CMake 3.25+ и распакованный SCS Telemetry SDK 1.16. Исходники библиотек интерфейса включены в vendor; скачивать зависимости при сборке не требуется.

~~~bat
cmake -S . -B build -A x64 -DSCS_SDK_ROOT="C:/path/to/scs_sdk_1_16" -DCARGO_CONTROL_BUILD_CHECKS=ON
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
~~~

DLL: build/bin/Release/CargoControlETS2.dll.

Для сохранения реального DX11-предпросмотра:

~~~bat
build\Release\overlay_dx11_check.exe menu.png notification.png
~~~

Лицензии используемых библиотек Dear ImGui и MinHook приведены в THIRD_PARTY_NOTICES.txt и соответствующих папках vendor.

## Исправления 0.6.1

Курсор меню использует относительное движение DirectInput вместо позиции системного указателя, который игра может возвращать в центр. Обработаны обычный и буферизованный ввод мыши. При открытом меню данные мыши, передаваемые игре через эти пути DirectInput, обнуляются; остальные устройства ввода проходят без изменений. После закрытия меню перехват ввода перестаёт изменять данные. Системная регистрация Raw Input и ограничение системного курсора не меняются.

Оформление: чёрный, белый и зелёный #AED9A4 — самый частый зелёный пиксель предоставленного логотипа. Дополнительные фоны нейтрально-серые; убраны зеленоватые поверхности и оранжевый текст ошибок. Яркость цвета проверяется на обычном и sRGB-буфере; палитра не подвергается повторному sRGB-преобразованию при выводе. Логотип не изменялся.

Прошли 6 офлайн-проверок, включая модель движения при постоянном возврате системного указателя в центр, кнопки мыши, ограничение координат, подавление движения для камеры, отсутствие двойного учёта, точные RGB-пиксели и установку/снятие DirectInput-перехвата. Проверен вход через ANSI-интерфейс DirectInput без захвата физической мыши. Это не заменяет проверку управления в ETS2 и совместимости с другими плагинами.
