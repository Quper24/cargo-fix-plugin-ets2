# Cargo Control 1.2.0

## Новое

- ATS Road Trip: массовое обновление предложений и ручное создание заказа для собственной машины.
- Грузоперевозки: галочка «Показывать все грузы» позволяет выбирать груз вне ассортимента компании и любую грузовую базу приёма.
- Галочка «Время на доставку ×4» для выбранного создаваемого грузового предложения.
- Автоматическая замена одного предложения при создании грузового или Road Trip заказа; галочки разрешения замены убраны.
- Проверка загруженного контента Road Trip и понятные сообщения о готовности профиля.
- Исправлен порядок подключения Road Trip: код общего планировщика проверяется до установки собственных грузовых перехватов.

## Выпуск

Главная ветка — `main`. Обычный файл выпуска — `CargoControl.dll`, версия интерфейса и ресурсов — 1.2.0. Тестовую сборку с суффиксом dev можно включить отдельным параметром CMake; он не связан с наличием функций Road Trip.

Пользователь подтвердил работу версии и времени доставки ×4 в игре. Проверки выпуска включают Release, CTest и DX11-предпросмотр грузовой формы и Road Trip. Сборки EXE для исследования и диагностика процессов в архив выпуска не входят.

Проверки релизной сборки: CTest 36/36, DX11-предпросмотр пяти состояний; версия ресурсов 1.2.0 и OriginalFilename CargoControl.dll подтверждены. SHA-256 DLL: `F778B85F2E460EECF3AA565B008C4DFD9C487727E038C0FE0C8BC44D0D2D5AAA`.
