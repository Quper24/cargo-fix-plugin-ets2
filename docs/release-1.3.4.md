# Cargo Control 1.3.4

Изменения относительно 1.3.3:

- Масштаб интерфейса регулируется кнопками «−» и «+» в верхней части любой вкладки: 75–300%, по умолчанию 130%. «Сброс» возвращает 130%. Изменения применяются и сохраняются сразу, отдельно от горячих клавиш.
- Окно автоматически помещается на экран. Если выбранный масштаб слишком большой, фактический масштаб показан в скобках. Выбранное значение сохраняется при смене разрешения.
- Масштаб применяется также к индикатору выполнения и уведомлениям.
- Основной шрифт — Segoe UI Semibold; надписи на зелёных кнопках — Segoe UI Bold. Шрифты загружаются с увеличенным разрешением для масштабирования.
- В верхней части меню доступен выбор языка: «Авто (как в игре)», «Русский», «English». Выбор применяется и сохраняется сразу.
- В режиме «Авто» русский используется для русского языка игры, английский — для остальных. Учитываются настройки игры и последние записи `Selected language` в журнале текущего запуска; обновление проверяется раз в секунду, в том числе при открытом меню.
- Настройки хранятся в секции `[Interface]` файла `CargoControl.ini`: `ScalePercent` и `Language` (`auto`, `ru`, `en`). Горячие клавиши сохраняются отдельно в `[Bindings]`.

Установка: при закрытой игре замените `CargoControl.dll` в `bin/win_x64/plugins`. Существующие горячие клавиши сохраняются.
