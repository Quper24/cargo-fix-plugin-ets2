# Cargo Control 1.3.1

Версия 1.3.1 в главной ветке `main`: поиск прямо в полях выбора, настраиваемое сочетание открытия меню и обновлённое оформление горячих клавиш. Релиз 1.3.1 ещё не опубликован; последний опубликованный выпуск — 1.3.0.

Плагин для **American Truck Simulator** и **Euro Truck Simulator 2**, Windows x64, DirectX 11. Меню: **Ctrl+Alt+F9**.

- Ограничивает автоматический подбор грузов для своего прицепа, чтобы уменьшить связанные с ним подтормаживания.
- Обновляет грузовые рынки с индикатором прогресса.
- Создаёт выбранный грузовой заказ: город и база отправления, груз, город и база назначения. Названия считываются из игры и модов.
- «Показывать все грузы» снимает ограничения ассортимента отправителя и получателя. Для собственного прицепа сохраняется фильтр совместимости.
- «Время на доставку ×4» увеличивает срок выбранного создаваемого грузового заказа.
- В ATS добавляет вкладку **Road Trip**: обновление предложений и ручное создание заказа для своей машины.
- В ETS2 добавляет вкладку **Coaches**: массовое обновление рейсов штатным генератором и ручной маршрут из 2–24 точек, включая отправление и конечную остановку.
- Замена одного предложения при создании разрешена автоматически, отдельных галочек подтверждения нет.

## Совместимость

Базовые грузовые функции поддерживают проверенные схемы 1.61 и 1.62; создание заказов, Road Trip и Coaches рассчитаны на 1.62. Последние цифры версии и хеш EXE не используются как условие допуска: плагин проверяет код функций и связи данных. При несовместимости причина записывается в `game.log.txt`.

Одна DLL подходит для обеих игр. Road Trip отображается в ATS, Coaches — в ETS2; доступность контента определяется по загруженным данным игры. Главная ветка выпуска — `main`.

## Сборка

Главная ветка — `main`, разработка — `dev`. CMake 3.25+, MSVC x64 и SCS Telemetry SDK:

```powershell
cmake -S . -B build-release -A x64 -DSCS_SDK_ROOT="путь/к/SDK" -DCARGO_CONTROL_BUILD_CHECKS=ON
cmake --build build-release --config Release
ctest --test-dir build-release -C Release --output-on-failure
```

Обычная сборка создаёт `CargoControl.dll` версии 1.3.1. Параметр `-DCARGO_CONTROL_DEVELOPMENT_BUILD=ON` создаёт `CargoControl-dev.dll` с пометкой dev. В каталоге плагинов игры оставляйте одну DLL Cargo Control.
