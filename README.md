# Cargo Control 1.2.0

Плагин для **American Truck Simulator** и **Euro Truck Simulator 2**, Windows x64, DirectX 11. Меню: **Ctrl+Alt+F9**.

- Ограничивает автоматический подбор грузов для своего прицепа, чтобы уменьшить связанные с ним подтормаживания.
- Обновляет грузовые рынки с индикатором прогресса.
- Создаёт выбранный грузовой заказ: город и база отправления, груз, город и база назначения. Названия считываются из игры и модов.
- «Показывать все грузы» снимает ограничения ассортимента отправителя и получателя. Для собственного прицепа сохраняется фильтр совместимости.
- «Время на доставку ×4» увеличивает срок выбранного создаваемого грузового заказа.
- В ATS добавляет вкладку **Road Trip**: обновление предложений и ручное создание заказа для своей машины.
- Замена одного предложения при создании разрешена автоматически, отдельных галочек подтверждения нет.

## Совместимость

Базовые грузовые функции поддерживают проверенные схемы 1.61 и 1.62; создание заказов и Road Trip рассчитаны на 1.62. Последние цифры версии и хеш EXE не используются как условие допуска: плагин проверяет код функций и связи данных. При несовместимости причина записывается в `game.log.txt`.

Одна DLL подходит для обеих игр. Road Trip отображается только в ATS; доступность контента определяется по загруженным данным игры. Coaches в этот выпуск не входит.

## Сборка

Главная ветка — `main`, разработка — `dev`. CMake 3.25+, MSVC x64 и SCS Telemetry SDK:

```powershell
cmake -S . -B build-release -A x64 -DSCS_SDK_ROOT="путь/к/SDK" -DCARGO_CONTROL_BUILD_CHECKS=ON
cmake --build build-release --config Release
ctest --test-dir build-release -C Release --output-on-failure
```

Обычная сборка создаёт `CargoControl.dll` с версией 1.2.0. Для отдельной тестовой DLL используйте `-DCARGO_CONTROL_DEVELOPMENT_BUILD=ON`: имя станет `CargoControl-dev.dll`, а версия получит пометку dev.
