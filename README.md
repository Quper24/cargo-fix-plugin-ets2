# Cargo Control ETS2 — 0.4.2 experimental

Для точного EXE ETS2 1.61.1.9 (SHA-256 B70C2357CC56EB5834EE47FEA3C60B2F2D4591383FF2AC479CFD3CD254301B8C).

## Изменение после сбоя 0.4

Версия 0.4 отозвана. Расширение парковочных массивов вызывало обращение к несуществующим физическим точкам карты (в полученном сбое индекс 2 при размере 2). Код создания дополнительных мест удалён. F9 теперь выполняет штатное полное обновление рынка компаний: старые предложения заменяются штатным количеством новых. Число зависит от компании и карты; пяти предложений в каждой компании не обещается. Пользователь согласовал замену предложений для F9.

## Управление

- F8 — добавление до пяти предложений на компанию на бирже грузов для своего прицепа, с сохранением неистёкших предложений.
- F9 — замена предложений штатного базового рынка (рынок грузоперевозок / заказы агентств) без увеличения вместимости.
- У режимов отдельные три слота лимита. Каждый успешный запуск занимает слот на 48 игровых часов; при окончании конкретного таймера освобождается один слот.
- Сон и быстрое перемещение продвигают таймеры вместе с игровым временем, пауза — нет.
- Загрузка сохранения/перезапуск таймеров телеметрии и смена объекта экономики сбрасывают лимиты. Покрытие разных сценариев загрузки требует игровой проверки.
- Новым ручным предложениям назначается срок 48 игровых часов от конкретного запуска. Удержание клавиши не повторяет запуск.
- Автоматическая генерация рынка грузоперевозок и агентств остаётся штатной. Ограничение одной попыткой относится только к режиму собственного прицепа.

## Установка и проверка

Закройте ETS2 и замените CargoControlETS2.dll в bin/win_x64/plugins. В папке plugins должна оставаться только одна версия Cargo Control ETS2. Другие плагины, изменяющие тот же генератор рынка, могут конфликтовать. Загрузите сохранение ДО использования F9 версии 0.4: этот билд не восстанавливает сохранённые некорректные дополнительные места. Журнал исходного сбоя сохранён в рабочей папке diagnostics/0.4-crash-2026-11-01 (в дистрибутив не включён).

INI необязателен. Для смены клавиш создайте CargoControlETS2.ini рядом с DLL: General/HotkeyVirtualKey=119 (F8), General/FreightHotkeyVirtualKey=120 (F9). Клавиши должны отличаться.

Уведомления встроены в DLL, язык читается из config.cfg ETS2 с учётом -homedir. Русский и английский встроены; для остальных языков используется английский. Папки переводов нет. Для показа поверх игры используйте оконный режим без рамки; эксклюзивный полный экран может скрывать уведомления.

Первый тест — на копии профиля: нажмите F9 в кабине, дождитесь обновления, проверьте работу компании на карте и оба раздела рынка, затем принятие заказа и сохранение/загрузку. В журнале ожидается [QS - Cargo Control] Freight / Quick jobs stock refresh finished с количеством обновлённых предложений. Нельзя считать отсутствие сбоя подтверждённым только по успешной сборке.

Проверены сборка MSVC, экспорт SCS и тесты независимых таймеров. В игре исправленная DLL ещё не проверена.

## Сборка

Нужны Visual Studio 2022 Build Tools с C++ и Windows SDK, CMake 3.25+ и распакованный SCS Telemetry SDK 1.16: https://modding.scssoft.com/wiki/Documentation/Engine/SDK/Telemetry

```bat
cmake -S . -B build -A x64 -DSCS_SDK_ROOT="C:/path/to/scs_sdk_1_16"
cmake --build build --config Release
```

DLL: build/bin/Release/CargoControlETS2.dll.
Для офлайн-проверок добавьте при настройке -DCARGO_CONTROL_BUILD_CHECKS=ON и выполните:

```bat
ctest --test-dir build -C Release --output-on-failure
```

src/plugin.cpp — биржа своего прицепа; src/freight.cpp — штатное обновление базового рынка; src/generation_limit.h — независимые игровые таймеры; src/notifications.cpp — уведомления. Продукт: Cargo Control ETS2, префикс журнала: [QS - Cargo Control].

## Оформление QUPER SIMULATOR (0.4.2)

Логотип из assets/quper-logo.png встроен в ресурс DLL (RCDATA 101) и рисуется в нижнем правом углу карточки. Рядом с игровым плагином файл изображения не нужен. Цвета: чёрный фон, белый основной текст, зелёный акцент RGB(180,221,171), снятый с предоставленного логотипа. Под изображение выделена отдельная колонка, высота карточки зависит от текста.

src/branding.cpp содержит общую отрисовку для DLL и офлайн-предпросмотра. Логотип не перерисован и не изменён; используется предоставленный PNG с сохранением пропорций. Рендер использует системную GDI+, дополнительных библиотек для установки не требуется.

Для предпросмотра при настройке CMake включите -DCARGO_CONTROL_BUILD_PREVIEW=ON, затем запустите build/Release/notification_preview.exe с путём выходного PNG. Программа рисует карточку вне экрана тем же кодом и из того же PNG-ресурса, что и DLL. Это проверяет оформление, но не отображение окна поверх ETS2 в конкретном режиме экрана.
